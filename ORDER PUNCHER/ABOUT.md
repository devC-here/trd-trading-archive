# ORDER PUNCHER: Fast Execution Bots

## Overview
Lightweight, rapid-fire order submission scripts designed to minimize latency between signal trigger and broker order acknowledgment.

## Key Files
- **`MAIN.PY` & `MAIN2.py`**: Execution scripts with pre-configured position sizing, slippage tolerance, and emergency cancel buttons.

## Purpose
Used for manual or semi-automated execution when immediate trade entry is required upon model signal detection.
