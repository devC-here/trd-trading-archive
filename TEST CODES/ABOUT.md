# TEST CODES: API & Order Logic Scratchpad

## Overview
A scratchpad directory containing short integration scripts for testing raw broker connections, order responses, and edge-case behavior.

## Key Files
- `test.py`, `test2.py`, `test4.py`, `test5.py`: Connection, authentication, and order roundtrip testing scripts.

## Purpose
Used during active debugging to verify network transport without firing full strategy runners.
