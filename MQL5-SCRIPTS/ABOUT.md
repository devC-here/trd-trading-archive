# MQL5-SCRIPTS: MetaTrader 5 Expert Advisors & Signal Generators

## Overview
Contains proprietary MQL5 scripts and compiled Expert Advisors for execution within MetaTrader 5.

## Key Files
- **`estimater.mq5`**: Source code of the MT5 Expert Advisor extracting live ticks, computing technical state metrics, and evaluating trade opportunities.
- **`estimater.ex5`**: Compiled binary executable ready for MT5 chart attachment.

## Purpose & Strategy
Bridges raw MT5 chart data directly into algorithmic pipelines and enables native execution inside institutional Forex brokers.
