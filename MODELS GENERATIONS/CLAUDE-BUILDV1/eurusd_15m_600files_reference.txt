======================================================================
  FILE NAMING CONVENTION
======================================================================

  Format: {condition_name}_{number}.csv
  Example: trend_bull_early_ignition_003.csv

  Numbers 001-006 = different random seeds (same condition, slight variation)
  All 6 files of same condition simulate the SAME market regime
  Variation between files = natural market randomness within regime

  Prefix guide:
    trend_bull_*    = directional bullish trend (various sub-types)
    trend_bear_*    = directional bearish trend (various sub-types)
    breakout_bull_* = squeeze-to-bull-breakout pattern
    breakout_bear_* = squeeze-to-bear-breakout pattern
    reversal_bull_* = price was going down, now reversing up
    reversal_bear_* = price was going up, now reversing down
    exhaustion_bull_*= bull trend ending (AVOID signal)
    exhaustion_bear_*= bear trend ending (AVOID signal)
    trap_bull_*     = looks bullish, fails (AVOID signal)
    trap_bear_*     = looks bearish, fails (AVOID signal)
    range_*         = no trend, sideways (AVOID signal)
