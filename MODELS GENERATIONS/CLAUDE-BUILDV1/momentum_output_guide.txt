HEAD 1 — momentum_state
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
0  down      multi-signal: ret_3<0, ret_3_z<0, ret_10<0, di_balance<0, tk_spread<0, price below cloud
1  neutral   insufficient multi-signal agreement
2  up        multi-signal: ret_3>0, ret_3_z>0, ret_10>0, di_balance>0, tk_spread>0, price above cloud

NOTE: Requires 4+ of 6 sub-signals to fire. Much stricter than v1.
      Neutral does not mean flat — it means the signal picture is mixed.

CONTEXT:
  up   + regime=trending   → continuation bias
  up   + regime=ranging    → fade candidate (at structure ceiling)
  up   + slope=falling     → exhaustion — peak is in
  down + structure=bearish → maximum short conviction

HEAD 2 — momentum_slope
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
0  falling   3+ of: ema_slope<0, ema_acc<0, adx_slope<0, momentum_decay<0
1  flat       neither 3+ rising nor 3+ falling
2  rising    3+ of: ema_slope>0, ema_acc>0, adx_slope>0, momentum_decay>0

CONTEXT:
  state=up  + slope=rising   → ignition / acceleration → chase
  state=up  + slope=falling  → distribution / exhaustion → do not enter
  state=neu + slope=rising   → momentum building, pre-entry monitoring
  slope=falling + vol=expand → blow-off or capitulation, trap risk


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
HEAD 3 — regime  [MASTER FILTER]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
0  ranging      er low, adx_z low, don_width contracting, momentum_persistence < 0
1  weak_trend   some trending signals, not all aligned
2  trending     er>0.5, adx_z>0.4, cloud aligned, momentum_persistence>0, MTF aligned
3  breakout     range_expansion+don_breakout+volume surge+break_strength all fire together

regime IS THE MASTER FILTER. Entry_quality cannot be "go" when regime=ranging.
All other head outputs should be down-weighted when regime confidence < 0.55.

CONTEXT:
  ranging   → all signals low trust. No entries. Watch for coil.
  weak      → signals valid but size-reduced. Confirm with entry_quality.
  trending  → signals high trust. Full size if entry_quality=go.
  breakout  → signals high trust but move already happening. Entry timing critical.
              breakout + vol=contracting = contradiction → treat as weak_trend.

HEAD 4 — volatility_state
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
0  contracting   atr_z<-0.6, range_expansion<0.8, don_width_z<-0.5
1  normal         between thresholds
2  expanding     atr_z>0.6 OR range_expansion>1.25, vol_regime_confirm firing

CONTEXT:
  contracting + regime=ranging  → coil forming. Flag for breakout watch.
  contracting + regime=trending → trend losing energy. Near exhaustion.
  expanding   + regime=breakout → breakout with vol fuel. Momentum entries valid.
  expanding   + slope=falling   → vol spike into fade. Trap setup. Avoid.
  expanding   + regime=ranging  → news spike / liquidity event. Unpredictable. Avoid.

HEAD 5 — structure_bias
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
0  bearish    4+ of: tp<0.42, don_pos<0.42, price below cloud, bearish cloud, di_bal<-0.2, tension<-0.1
1  neutral    neither 4+ bull nor 4+ bear
2  bullish    4+ of: tp>0.58, don_pos>0.58, price above cloud, bullish cloud, di_bal>0.2, tension>0.1

KEY: structure_bias incorporates Ichimoku cloud position, Donchian position, AND tension.
     Tension > 0 means displacement has structural room to continue.
     Tension < 0 means displacement is hitting a structural wall — exhaustion risk.

CONTEXT:
  bullish + momentum=up   + regime=trending   → max long confidence
  bearish + momentum=down + regime=trending   → max short confidence
  bullish + momentum=down                     → conflict → wait for resolution
  neutral + high signal_conf                  → model uncertain on structure → reduce size

HEAD 6 — entry_quality  [PRIMARY SIGNAL HEAD]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
0  avoid    regime=ranging OR (er<0.12 AND |ret_3|<0.25)
1  wait     some conditions met, not all 5 pillars aligned
2  go       all 5 must be true: regime>=trending, vol confirmed, er>0.30,
            MTF aligned + persistence>0, slope and state agree, |mrs|<2.5

go CANNOT fire when:
  - regime = ranging (hard rule in label logic)
  - momentum_state ≠ direction implied by momentum_slope
  - mean_reversion_stretch > 2.5 (overextended)

Use signal_conf for position sizing:
  >= 0.75   → full size
  0.60-0.74 → 0.6× size
  0.50-0.59 → 0.35× size or skip
  < 0.50    → treat as avoid regardless of label

CONTEXT ENGINE ROUTING (parse _summary)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

s = result["_summary"]

LONG MOMENTUM:
  s["momentum"]=="up" and s["slope"]=="rising"
  and s["regime"] in ("trending","breakout")
  and s["structure"]=="bullish"
  and s["signal"]=="go" and s["signal_conf"] > 0.60

SHORT MOMENTUM:
  s["momentum"]=="down" and s["slope"]=="falling"
  and s["regime"] in ("trending","breakout")
  and s["structure"]=="bearish"
  and s["signal"]=="go" and s["signal_conf"] > 0.60

EXHAUSTION / FADE SETUP:
  s["slope"]=="falling" and s["vol"]=="expanding"
  and s["signal"] != "go"
  → momentum dying into vol spike. Alert other model (reversal / microstructure).

COIL / PRE-BREAKOUT:
  s["regime"]=="ranging" and s["vol"]=="contracting"
  and s["signal"]=="avoid"
  → no trade. Watchlist. Breakout imminent.

CONFLICT (route to override logic):
  s["momentum"] != implied direction of s["structure"]   # momentum vs structure mismatch
  s["slope"] direction != s["momentum"] direction        # state vs slope mismatch
  s["regime"]=="breakout" and s["vol"]=="contracting"    # vol contradiction

REGIME FILTER OVERRIDE:
  if s["regime"]=="ranging": ignore all other signals, force avoid.
  if result["regime"]["conf"] < 0.50: downgrade to weak_trend logic.
