# RESEARCH: Mathematical & Statistical Price Action Tests

## Overview
Exploratory signal processing and mathematical market analysis scripts testing theoretical edges.

## Key Files
- **`FFT.py`**: Fast Fourier Transform frequency domain analysis detecting dominant cyclical periodicity in price action.
- **`parkinson.py`**: Parkinson extreme-value volatility estimator computing true intraday diffusion variance from High-Low ranges.
- **`50%touch-test.py` & `50_touch-test.py`**: Statistical test assessing the probability of price revisiting the 50% midpoint of impulse candles and Fair Value Gaps.
- **`efficiency-test.py`**: Fractal efficiency and directional persistence testing across various time horizons.

## Purpose
Provides mathematical and statistical proof-of-concept validation before codifying concepts into neural network features or rule engines.
