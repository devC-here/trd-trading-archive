# PRODUCTION-R: Live Production Deployment Packages

## Overview
The operational deployment hub containing pre-packaged live execution suites, model weights, and one-click Windows execution batch files (`.bat`).

## Key Subdirectories
- **`METATRADER5/` through `METATRADER5(V5)/`**: **PROPRIETARY LIVE RUNNERS**. Active MetaTrader 5 execution packages with validated model weights and parameter configurations.
- **`CLAUDE-H1-V1-( GEMINI)/` & `CLAUDE-V4 (15M-H1)/`**: Stable release packages combining H1 higher-timeframe models with live order execution.
- **`run files/`**: Pre-configured launcher batch scripts for immediate deployment.

## Purpose
Provides turnkey, fully tested execution directories ready to be run on trading VPS servers or local trading terminals.
